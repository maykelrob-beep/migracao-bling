Manual do Aplicativo Migração Bling Python

1. Finalidade

Este aplicativo tem como finalidade auxiliar na migração controlada de cadastros entre contas autorizadas do Bling ERP.

2. Autorização

O aplicativo utiliza OAuth 2.0 para solicitar autorização individual de cada conta Bling. As credenciais devem permanecer armazenadas em ambiente privado.

3. Consulta de dados

A etapa inicial realiza consultas de produtos, categorias e subcategorias, sem alterar os registros existentes.

4. Comparação

Os cadastros das contas de origem e destino serão comparados para identificar registros existentes e ausentes.

5. Migração

Futuras operações de inclusão dependerão de autorização adequada, conferência dos dados e validação prévia.

6. Segurança

O aplicativo não deve publicar tokens, credenciais ou informações comerciais das contas integradas.

7. Situação do projeto

Aplicativo em desenvolvimento. Funcionalidades de migração ainda não estão disponíveis para uso operacional.
